# Smart Zero-Flag CLI and Auto-SIEM Clipboard Ingestion

During live SOC Tier-1 alert triage, analysts routinely copy either raw command lines or full JSON/JSONL event payloads directly from QRadar, Wazuh, or SentinelOne into their clipboard, or pipe/pass a file path on the command line. Requiring explicit flags (`-p`, `-f`, `-c`, `--copy-note`, `--sigma`) for every single invocation creates unnecessary flag fatigue under shift pressure, while a flat `argparse` help listing of 20+ options obscures the primary workflow.

To deliver zero-friction execution while preserving 100% backward compatibility with existing scripts and CI pipelines—using strictly Python standard library (`argparse`, `json`, `os`, `sys`)—`cmd-unmask` v0.6 adopts **Zero-Flag Triage** and **Auto-SIEM Clipboard Ingestion**:

1. **Positional Auto-Detect & Clipboard Default:** An optional positional `target` argument (`nargs="?"`) automatically dispatches to file ingestion (`ingest_source()`) when `os.path.isfile(target)` is true, or single-command triage otherwise. When invoked with no positional target, no explicit `-c`/`-f`/`-p`, and a TTY stdin, `cmd-unmask` reads directly from the OS clipboard without requiring `-p`. Non-TTY stdin pipes remain auto-ingested.
2. **Auto-SIEM Clipboard Ingestion:** When raw clipboard or single-string input begins with `{` or `[` (or multi-line JSONL), the **Ingestion Pipeline** attempts structured SIEM JSON/JSONL parsing first, automatically extracting `CommandLine`, `ParentImage`, `ParentCommandLine`, and `Image` via existing `DEFAULT_*_FIELDS`—falling back safely to raw command text if parsing fails.
3. **Smart Interactive Defaults & Grouped `--help`:** Interactive terminal runs automatically copy the `[SOC TRIAGE NOTE]` to the clipboard (`--no-copy` overrides) and surface Sigma detection hints/output for non-benign findings (`--no-sigma` overrides), while explicit batch/JSON/CI invocations remain deterministic and side-effect free. `argparse` options are organized into clean argument groups (`Input Sources`, `Output & Triage UX`, `Process Context`, `Detection & CI Gates`) so `--help` stays scannable.
