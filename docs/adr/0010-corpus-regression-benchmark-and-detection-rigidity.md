# Corpus Regression Benchmark and Detection Rigidity Gate

`cmd-unmask` validates its de-obfuscation accuracy, behavioral classification, and False Positive resilience against a curated, versioned **Regression Corpus** using 100% Python standard library tooling (`json`, `pathlib`, `time`, `dataclasses`, `unittest`) with zero external dependencies. Each **Corpus Fixture** pairs a raw obfuscated or benign administrative command line with deterministic expectations (`expected_severity`, `min_risk_score`, `max_risk_score`, `expected_techniques`, `expected_iocs`, `must_not_match`). Running the **Detection Rigidity Gate** (`--benchmark`) executes the full `unmask_command` pipeline in-process under bounded `TriageConfig` ceilings, measures precision, recall, false-positive rate, and per-command latency (`time.perf_counter()`), and exits non-zero when any fixture regresses or breaches latency/false-positive thresholds. Keeping the benchmark harness offline, deterministic, and dependency-free ensures SOC analysts and CI pipelines can verify rule changes on air-gapped or resource-constrained workstations without installing external test frameworks or datasets.
