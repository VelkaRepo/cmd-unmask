# Contextual IOC Validation to Suppress Namespace and Hex-Blob False Positives

To preserve Detection Rigidity on PowerShell and Windows command lines, standalone domain extraction requires a valid IANA or special-use TLD and explicitly rejects known `.NET`/PowerShell namespaces (`System.*`, `Microsoft.*`, `Windows.*`, `Text.Encoding`, `IO.*`, `Net.*`, `Diagnostics.*`, `Runtime.*`) as well as executable/script filenames (`.exe`, `.dll`, `.ps1`, `.bat`, `.cmd`, `.vbs`, `.js`, `.hta`, `.sh`) unless the host appears inside an explicit URL authority (`http(s)://<host>/...`). Hash extraction enforces strict non-hex boundaries (`(?<![0-9a-fA-F])[0-9a-fA-F]{32|40|64}(?![0-9a-fA-F])`), rejects uniform repeating characters, and skips spans already decoded as hex-encoded command text.
