# Behavioral Capability Summary and Concise Triage UX

SOC Layer 1 analysts triaging multi-line PowerShell, inline C# (`Add-Type`), or credentialed VA scanner scripts face two recurring friction points in terminal and ticket outputs: (1) noisy, redundant de-obfuscation timelines when consecutive DAG edges produce identical payload states or dump hundreds of lines of inline script, and (2) missing non-IOC operational context (such as file writes, Win32/.NET API imports, and registry modifications) alongside unclear `BENIGN` verdicts when an **Authorized Audit Baseline** suppresses obfuscation flags.

To keep `cmd-unmask` fast, readable, and strictly dependency-free (100% Python stdlib `re`, `dataclasses`, `argparse`), this architecture introduces two new `TriageVerdict` fields—**Behavioral Capability Summary** (`capabilities: list[str]`) and **Verdict Rationale** (`verdict_rationale: list[str]`)—computed statically during classification, paired with UX upgrades in the renderer and CLI:

1. **Non-IOC Capability Extraction:** Statically extract operational behaviors from the unmasked payload (e.g., file write/dropper paths, Win32/.NET P/Invoke API imports, registry persistence/query keys, and process-creation primitives) into `TriageVerdict.capabilities` with deterministic deduplication and ordering.
2. **Explicit Verdict Rationale:** Record human-readable explanation strings in `TriageVerdict.verdict_rationale` whenever a verdict is `BENIGN` (including explicit **Authorized Audit Baseline** suppression reasons) or escalated by behavioral rules, so analysts never have to guess why an encoded command scored `0`.
3. **Deduplicated Timeline & Smart Truncation:** Collapse consecutive `ProvenanceStep` entries in `build_unmasking_timeline()` when normalized payload text is identical, and apply head/tail line truncation (with total line/char counts) to multi-line payloads in pretty terminal output and `[SOC TRIAGE NOTE]` by default, overridable via `--full`. Existing JSON/JSONL keys remain backward-compatible with additive fields only.
